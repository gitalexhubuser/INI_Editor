INI Settings Editor — установка и проверка
===========================================

Что лежит в папке
-----------------
ini_editor.py                 Графический редактор .ini.
register_ini_association.py   Регистрация/удаление обработчика .ini в Windows.

1. Установите зависимость, если она ещё не установлена
------------------------------------------------------
Откройте CMD/PowerShell в этой папке и выполните тем Python, которым будете
пользоваться для редактора:

    python -m pip install customtkinter

2. Сначала проверьте вручную
----------------------------
Сделайте копию тестового .ini, затем запустите:

    python ini_editor.py "C:\путь\к\тестовому.ini"

Убедитесь, что открылся именно выбранный файл, измените тестовое значение,
нажмите «Сохранить всё» и проверьте содержимое файла.

3. Назначьте редактор для .ini
------------------------------
Запустите в этой папке:

    python register_ini_association.py install

Регистрация действует для текущей учётной записи Windows и для .ini-файлов
в любых папках. Если Windows 10/11 продолжит открывать .ini в Блокноте,
выберите INI Settings Editor вручную в Параметры → Приложения → Приложения
по умолчанию → выбор приложения по типу файла → .ini. Windows может защищать
уже выбранное пользователем приложение от изменения через реестр.

4. Вернуть прежнюю регистрацию
-----------------------------
Выполните:

    python register_ini_association.py uninstall

Если вы вручную успели выбрать редактор в окне «Приложения по умолчанию»,
после удаления регистрации верните прежнее приложение для .ini там же.

Исправления в этой версии
------------------------
- Аргумент с путём к файлу принимается при запуске из Проводника.
- При чтении и записи сохраняется исходная кодировка (UTF-8/BOM, UTF-16,
  системная Windows-кодировка; предусмотрен CP1251 fallback).
- Сохраняются исходные окончания строк (CRLF/LF/CR).
- Запись выполняется через временный файл и атомарную замену.
- Если сохранение не удалось, редактор не закрывается и не переключает папку
  при ответе «Сохранить»; несохранённые данные остаются в памяти.

Важно: перед первой проверкой используйте копию INI-файла, а не единственный
экземпляр рабочих настроек.
