INI Settings Editor — инструкция
================================

Что делает редактор
-------------------
- Показывает .ini-файлы из выбранной папки.
- Значения true/false (а также 0/1, yes/no, on/off, enabled/disabled)
  редактируются двумя явными кнопками FALSE и TRUE, а не текстом.
- Для целых чисел из диапазона 0–100 или диапазона, указанного в комментарии
  к параметру (например, ; range: 0-100), доступны слайдер и точный ввод числа.
- Шрифт параметров увеличен, вертикальные отступы уменьшены.
- Любое изменение автоматически записывается на диск через короткую паузу
  после окончания ввода. Кнопки «Сохранить всё» нет.
- Сообщение о сохранении появляется только после реальной записи и исчезает.
- Сохраняются распознанная кодировка и окончания строк исходного файла.

1. Установить компоненты для запуска исходного Python-файла
----------------------------------------------------------
Откройте CMD в папке проекта и выполните:

    py -m pip install customtkinter pyinstaller

2. Проверить исходный файл редактора
------------------------------------
    py ini_editor.py "C:\путь\к\копии-тестового.ini"

Проверьте на копии INI, что переключатели меняют true/false, ползунок
и ручной ввод обновляют одно и то же значение, а изменения автоматически
попадают в файл после небольшой паузы.

3. Собрать обычное Windows-приложение EXE
-----------------------------------------
В той же папке выполните:

    py -m PyInstaller --noconfirm --clean --windowed --name "INI Settings Editor" --collect-all customtkinter ini_editor.py

Готовое приложение будет здесь:

    dist\INI Settings Editor\INI Settings Editor.exe

Не перемещайте EXE после назначения приложения по умолчанию.

4. Добавить приложение в Windows и назначить его для .ini
---------------------------------------------------------
После сборки выполните из папки проекта:

    py register_ini_association.py install

Установщик автоматически выберет собранный EXE, если он найден в папке dist.
Если EXE ещё не собран, будет зарегистрирован запуск через Python.
Затем откройте Параметры Windows → Приложения → Приложения по умолчанию,
найдите тип файла .ini и выберите INI Settings Editor. При необходимости
перезапустите окно «Параметры».

5. Удалить регистрацию
----------------------
    py register_ini_association.py uninstall

Важное замечание
----------------
Перед первой проверкой работайте с копией конфигурации. При ошибке записи
редактор оставляет файл отмеченным как несохранённый и показывает ошибку.
Числовое поле нельзя покинуть или закрыть редактор, пока там введено
некорректное (нецелое) значение — исправьте его или верните прежнее.
